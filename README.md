# Tic Tac Toe Game

This is a simple Tic Tac Toe game developed using HTML, CSS, and JavaScript.

## Features
- Two-player game
- Winner detection
- Draw detection
- Reset game button
- New game button

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Play
1. Open the game in your browser.
2. Two players take turns clicking the boxes.
3. The first player to match three marks in a row, column, or diagonal wins.
4. If all boxes are filled without a winner, the game ends in a draw.
5. Click Reset or New Game to play again.
